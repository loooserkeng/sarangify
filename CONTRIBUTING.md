# Contributing to SARANGIFY

Thanks for your interest in improving SARANGIFY. Please keep contributions focused on the existing Android project and its implemented behavior.

## Before you start

- Search existing issues and pull requests for related work.
- For a significant change, open an issue first to discuss the approach.
- Keep changes focused, explain user-visible behavior, and do not include secrets or personal data.

## Pull requests

1. Create a branch from `main`.
2. Make the smallest complete change that addresses the issue.
3. Build the Android app with `./gradlew assembleDebug` and run relevant checks.
4. Describe the change and checks performed in your pull request. Include screenshots for UI changes when helpful.

Please preserve the project's GPL-3.0 license and original attribution notices. By contributing, you agree that your contribution is offered under the project's existing license.

Be respectful and follow the [Code of Conduct](CODE_OF_CONDUCT.md).
